Not sure which one to use?

These are rough guides, not strict rules — go with whatever actually matches your hardware.

Low-end

  • 4–8GB RAM
  • Integrated graphics
  • Older / lower-power CPUs

Grab the Low-End preset first.

Mid-range

  • 8–16GB RAM
  • GTX / RX class GPUs

Whichever matches your CPU — AMD or Intel.

High-end

  • 16GB+ RAM
  • RTX / RX high-performance GPUs

Try Game Processor and Network together.
